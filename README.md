# Web3 MyData Manager (Smart Identity Vault)

A decentralized personal data control platform that allows users to securely encrypt,
store, and share personal data using IPFS, Ethereum smart contracts, and MetaMask.

## Structure
- **backend/** — .NET Core API for handling data logic.
- **frontend/** — React app for the dashboard.
- **smart-contract/** — Solidity smart contract for permissions and data records.

## Tech Stack
C#, React.js, Solidity, ethers.js, IPFS, AES encryption, MetaMask.
